# 3–5 分钟比赛视频脚本（仅实测数据可称“实测”）

| 时间 | 画面与口播重点 |
| --- | --- |
| 0:00–0:35 | 展示 370 直流电机、固定方式、LIS3DH 与领航者 Zynq，说明传感器 → PL SPI/FIFO/16点 X轴特征 → AXI → PS ARM → UART0 → PC。展示安全防护、线缆固定，不触碰旋转部件。 |
| 0:35–1:05 | 用已静态核验的串口助手选择实际 COM、115200/8N1，展示真实固定 CSV 行与 `# source=PL`。指出 `seq` 持续变化。 |
| 1:05–1:20 | 在助手里点击关闭串口；确认端口释放，再打开 Python 上位机连接同一 COM。两程序不能同时占用端口。 |
| 1:20–1:55 | 展示实时 SEQ、Peak、原始 RMS、STATUS、DROP、波形和最新原始报文；解释 RMS 包含重力/直流，`STATUS` bit2 是历史锁存，`DROP=0` 不等于传感器从未覆盖。 |
| 1:55–2:35 | 在固定姿态与转速下选择“正常运行”，采 30 条实测基线；展示界面公开的增强/超阈值。基线尚未完成时保持“未标定”。 |
| 2:35–3:20 | 在防护与固定条件下做可重复的受控扰动，或改变已标记的运行条件；展示 Peak/原始 RMS 趋势与阈值变化。明确说“运行状态变化监测”，不宣称机械故障已诊断。 |
| 3:20–4:05 | 停止记录，展示 CSV 中来源、阶段、真实接收时间和八个 UART 字段；选择两组**实测** CSV 作简单对比。 |
| 4:05–4:30 | 总结：PL 实时采集与特征、PS 读 AXI/UART、PC 显示和留存已打通；故障阈值、去直流量和更严格 DDR/长时稳定性仍待完成。 |

若尚无“真实异常”工况样本，屏幕标题、字幕和口播都使用“运行状态变化监测”；离线 Demo 若入镜必须持续显示“模拟数据 · 非实测”，不能剪接成实机结果。
