# 电机调速与受控扰动实验

采集日期：2026-11-03。实验对象为 370 直流电机。

| 文件 | 工况 | 操作过程 | 记录窗口数 |
|---|---|---|---:|
| 1.csv | 正常运行对照 | 从低速逐步调到高速 | 105 |
| 3.csv | 转轴受控扰动 | 电机转动时转轴受到外部干扰，同时从低速逐步调到高速 | 47 |

工况和调速过程依据实验操作者说明；CSV 的 phase 字段分别为“正常运行”和“受控扰动”。原始文件保持原名及字节内容。每组的 events.csv 为事件记录，summary.json 为采集程序统计。comparison_screenshot.png 是本次上位机对比截图。comparison_summary.json 为从 CSV 重新计算的整段统计。

## 结果

| 指标（counts） | 正常运行 | 受控扰动 |
|---|---:|---:|
| Peak 中位数 | 66.00 | 606.00 |
| Peak 均值 | 97.82 | 940.77 |
| 原始窗口 RMS 中位数 | 35.59 | 464.67 |

本次受控扰动组的 Peak 和原始窗口 RMS 整体高于正常对照组，系统记录并显示了两种工况下的特征差异。两组均包含从低速到高速的调速过程，记录时长不同，未记录逐档转速和扰动施加时刻，因此表中结果为整段采集统计，不用于同转速下的扰动效应估计或故障分类准确率计算。

RMS = sqrt(sum_squares / sample_count)，包含重力与直流分量，单位为传感器原始计数。每个窗口样本数为 16。

## 文件核对

两组共 152 条记录，来源均为 PL。窗口序号递增，DROP 字段均为 0，平方和高低位组合与 RMS 重算一致。两份采集摘要中的 parse_errors、serial_errors 均为 0。

事件文件记录的是 sequence_gap。相邻记录的窗口序号间隔与 PS 跳过窗口字段一致，不能将这些事件条数直接当作串口传输错误或 FIFO 丢帧数。STATUS 均为 0x00000015，具体位定义见工程寄存器说明。anomaly_events 为 0 只表示没有记录到告警事件，不能据此推断扰动不存在或检测准确率。
