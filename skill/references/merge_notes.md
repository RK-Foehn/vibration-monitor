| 内容 | 处理 |
|---|---|
| E0 至 E4 证据分级 | 纳入入口和交付模板；标签针对测试对象，不当成整机完成度 |
| STATUS=0xFF、bit3/bit7 | 对照本地 RTL 后纳入；合法状态组合与链路错误仍需交叉验证 |
| BD .v 包装、MISO、时钟 XDC | 纳入条件式排查，避免把特定工具报错泛化 |
| ILA 常量位、bit/ltx | 纳入；完整探针问题保留“历史未修复”边界 |
| Vitis 界面滞后、HLS、DDR | 纳入真实运行与小范围 DDR 检查的边界 |
| UART 周期/表头/诊断 | 本次对照 C 源码，补入解析模板 |
| W1 至 W8 | 去重合并为按目标选用的工作流，合并重复步骤 |
| U1 至 U3 | 保留为待验收架构、时序与实验模板，不标已验证 |
| E: 盘、COM8、旧目录名、51 文件/46 检查 | 不固定到工作流；运行时核实实际状态 |
| 历史姿态数值、LIVE、DDR 结果 | 不转成本次结果，保留来源和验证层级 |
| 首次 100ms 导致 overrun | 仅保留为假设 |
| 每次都先计划再确认、旧 Git 禁令 | 不继承为额外审批流程；服从本次用户授权 |
| 电机供电/桥芯片型号/DDR 型号 | 不从复盘直接下新接线或配置结论，要求核对当前硬件 |
